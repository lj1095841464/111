AI 辅助的个人敏感信息自动脱敏工具
项目简介
本项目是基于 Python + Flask + 轻量级 NER 命名实体识别开发的AI 辅助个人敏感信息自动脱敏 Web 工具。可智能识别文本中的手机号、身份证号、银行卡号、中文姓名、居住地址等敏感隐私信息，采用正则规则 + AI 实体识别双引擎方案，支持掩码脱敏、智能替换脱敏，全程本地离线运行，原始数据不上传云端，兼顾隐私安全与使用便捷性。
适合课程设计、本科毕业设计、日常办公文本隐私脱敏使用。
