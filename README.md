# 111 - AI 辅助个人敏感信息脱敏工具

一个基于 Python + Flask + 轻量级 NER 命名实体识别的 Web 脱敏工具，支持手机号、身份证、银行卡、中文姓名、居住地址等敏感信息的智能识别与掩码脱敏。全程本地离线运行，数据不上传云端。

## 功能

- ✅ 手动输入文本脱敏
- ✅ 本地 .txt 文件上传解析
- ✅ 智能识别 5 类敏感信息：手机号、身份证、银行卡、中文姓名、居住地址
- ✅ 正则规则 + AI NER 双引擎识别，降低漏报/误报
- ✅ 掩码脱敏 + 替换脱敏两种模式
- ✅ Web 可视化界面，浏览器直接操作
- ✅ 本地离线运行，数据不上传第三方服务器
- ✅ 脱敏绒果预览、复制、保存

## 技术栈

| 技术 | 用途 |
|------|------|

| Flask | Web 框架 |

## 快速开始

### 安装

```bash
git clone https://github.com/lj1095841464/111.git
cd 111
pip install -r requirements.txt
```

### 运行

```bash
python app.py
```

浏览器打开 http://127.0.0.1:5000

### 使用流程

1. 进入 Web 首页
2. 手动粘贴文本 或 上传本地 .txt 文件
3. 点击 **敏感信息识别**，自动标记隐私内容
4. 点击 **一键脱敏**，生成脱敏后文本
5. 查看前后对比，可复制或保存到本地

## 技术要点

- **AI + 规则双引擎**：正则匹配结构化数据（手机号/身份证/银行卡），NER 模型识别非结构化数据（姓名/地址）
- **本地离线**：所有数据在本机处理，无云端上传，保护隐私
- **轻量化部署**：依赖简单，普通电脑即可运行
- **Web 可视化**：不用命令行，浏览器直接操作
- **适配毕业设计**：结构完整，技术点饱满，可直接配套毕业论文使用
